# Security Policy

## Supported Versions

Please use the latest version of the application. Older versions are not supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| Latest  | :white_check_mark: |
| Older   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please follow these steps:

1. **Do not open a public issue.** This could expose the vulnerability to malicious actors before a fix is ready.
2. Send an email to the repository owner or create a private vulnerability report via GitHub at [https://github.com/Aadil12003/Muslim-AI-/security/advisories/new](https://github.com/Aadil12003/Muslim-AI-/security/advisories/new).
3. Include detailed instructions on how to reproduce the vulnerability.
4. Provide an assessment of the potential impact.

We take all security reports seriously and will strive to investigate and resolve them promptly. You will be notified of the progress and when the issue has been fixed.
