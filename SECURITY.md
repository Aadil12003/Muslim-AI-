# Security Policy

## Supported Versions

Currently, only the latest version of this project is actively supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| Latest  | :white_check_mark: |

## Reporting a Vulnerability

We take the security of this project seriously. If you discover a security vulnerability, please do **NOT** report it through public issues or pull requests.

Instead, please send an email to the repository owner or use GitHub's private vulnerability reporting feature if enabled. We will endeavor to respond to your report as quickly as possible and work with you to resolve the issue.

Please include the following information in your report:
* A description of the vulnerability.
* Steps to reproduce the issue.
* Potential impact.
